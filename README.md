# Pool - Telegram Mini App (تست اولیه)

## فایل‌ها (هر سه باید کنار هم، در ریشهٔ مخزن GitHub باشند)
- `index.html`  : خود بازی
- `phaser.min.js` : موتور بازی (نسخهٔ 3.80.1، محلی تا به CDN وابسته نباشد)
- `README.md`   : همین راهنما (اختیاری)

حجم دانلود کاربر: حدود ۳۳۰ کیلوبایت (فشرده).

## نکته‌ها
- بازی افقی است. اگر گوشی عمودی باشد پیام «گوشی را بچرخانید» نمایش داده می‌شود.
- برای تست تمام‌صفحه در تلگرام، به آخر لینک مینی‌اپ `?fs=1` اضافه کنید.
- دکمهٔ JAWS فقط برای دیدن دماغه‌ها و ناحیهٔ پاکت‌هاست (برای تنظیم).
